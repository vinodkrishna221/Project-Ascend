# Assets Directory

This directory contains static assets for the mobile application.

## Required Assets

### Authentication Flow
- `welcome-illustration.png` - Welcome screen illustration showing diverse students connecting
  - Dimensions: 300x200px
  - Format: PNG with transparency
  - Style: Friendly, inclusive illustration of students from different backgrounds

### Icons
- App icons for different platforms (iOS/Android)
- Tab bar icons
- Authentication flow icons

### Images
- Placeholder images for empty states
- Success/error state illustrations
- Onboarding illustrations

## Asset Guidelines

1. **Accessibility**: All images should have meaningful alt text
2. **Performance**: Optimize images for mobile (WebP when possible)
3. **Consistency**: Follow the design system color palette and style
4. **Inclusivity**: Ensure diverse representation in all illustrations
