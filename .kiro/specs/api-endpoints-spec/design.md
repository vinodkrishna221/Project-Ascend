# API & Backend Design Document

## Overview

The API & Backend system leverages Supabase as the primary backend infrastructure, utilizing its auto-generated REST and GraphQL APIs, Edge Functions for custom business logic, and built-in features for authentication, storage, and real-time functionality. This system extends Supabase's capabilities with custom endpoints and business logic while maintaining high performance, security, and developer experience standards.

## Architecture

### Supabase-First Architecture

```
┌─────────────────────────────────────────────────────────────────┐
│                    Supabase Backend Platform                   │
├─────────────────────────────────────────────────────────────────┤
│  ┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐ │
│  │   PostgreSQL    │  │   Supabase      │  │   Supabase      │ │
│  │   Database      │  │   Auth          │  │   Storage       │ │
│  └─────────────────┘  └─────────────────┘  └─────────────────┘ │
├─────────────────────────────────────────────────────────────────┤
│  ┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐ │
│  │   Auto-Generated│  │   Edge          │  │   Real-time     │ │
│  │   REST/GraphQL  │  │   Functions     │  │   Subscriptions │ │
│  └─────────────────┘  └─────────────────┘  └─────────────────┘ │
├─────────────────────────────────────────────────────────────────┤
│  ┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐ │
│  │   Row Level     │  │   API Gateway   │  │   Analytics &   │ │
│  │   Security      │  │   & Routing     │  │   Monitoring    │ │
│  └─────────────────┘  └─────────────────┘  └─────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
```

### API Layer Architecture

```
Frontend Applications → Supabase Client → API Gateway → Database/Services
        ↓                    ↓              ↓              ↓
   Web/Mobile Apps → Authentication → Auto-Generated APIs → PostgreSQL
        ↓                    ↓              ↓              ↓
   Direct DB Access → JWT Validation → Custom Edge Functions → RLS Policies
        ↓                    ↓              ↓              ↓
   Real-time Subs → Permission Check → Business Logic → Storage/Files
```

## Testing Strategy

### API Testing Framework

```typescript
describe('Supabase API Integration', () => {
  describe('Authentication', () => {
    it('should authenticate user with valid credentials', async () => {
      const result = await authService.signInWithEmail('test@college.edu', 'password');
      expect(result.user).toBeDefined();
      expect(result.session).toBeDefined();
    });
    
    it('should enforce RLS policies', async () => {
      const { data, error } = await supabase
        .from('posts')
        .select('*')
        .eq('user_id', 'other-user-id');
        
      expect(data).toHaveLength(0); // Should not see other user's private posts
    });
  });
  
  describe('Edge Functions', () => {
    it('should process notifications correctly', async () => {
      const result = await edgeFunctions.invoke('process-notification', {
        type: 'post_kudos',
        userId: 'test-user',
        data: { postId: 'test-post' }
      });
      
      expect(result.data.status).toBe('processed');
    });
  });
});
```
